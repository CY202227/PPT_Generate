## 使用边界

该官方公开 PPTX 的 21 页均由整页图片组成，没有可编辑文字、原生表格或原生图表。
因此只作为视觉和内容组织参考，不能交给现有文字替换管线作为可编辑模板。
`inventory.json` 的空文本数组与零原生图表数量表示图片封装，不表示页面视觉上没有文字或图表。
`preview-1.png`、`preview-3.png`、`preview-5.png` 是原稿中直接提取的图片。
已人工查看第 3 页目录和第 5 页季度业务指标，尚未逐页完成视觉评审。

## 第一版生成验收

目标是无需用户具备 PPT 排版技能，即可从上游 agent 提供的材料生成可用的企业汇报。
参考其内容层级、对齐、留白、指标比较和注释表达，不要求像素复刻或使用微软品牌。

首轮生成 8–10 页中文模拟企业季度汇报，覆盖封面、目录、摘要、指标比较、趋势图、业务分析、风险、后续计划。
模拟数据必须明确标记，不能冒充真实公司业绩。参考稿中的复杂财务附录不作为首轮必需项。

- 内容：每页围绕一个明确主题；数字、单位、时间区间与输入材料一致；不编造缺失数据。
- 排版：标题和正文有清晰层级；没有文字溢出、遮挡、越界或无法阅读的过小字体；中文换行合理。
- 数据展示：比较口径明确；图表标明单位、时间和系列；表格能清楚读出指标变化。
- 可编辑性：正文、表格和适用的图表使用原生对象；不能用整页截图代替可编辑输出。
- 工具契约：返回真实导出状态、独立任务目录、PPTX 路径、逐页预览和检查报告。
- 修改能力：能修改指定页并重新导出，保留其他页内容。
- 稳定性：同一输入连续运行三次均得到可打开的文件，页数符合要求；失败不会报告成功。

验收证据应包含输入材料、生成中间结果、PPTX、逐页预览和问题清单。
自动检查与人工视觉检查共同决定是否通过，成功导出文件本身不代表质量达标。
